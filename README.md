# Каталог студентов

## 1. Описание проекта

«Каталог студентов» — веб-приложение, разработанное на Laravel для хранения и отображения информации о студентах.

Приложение позволяет добавлять студентов, указывать их ФИО, учебную группу и электронную почту, а также просматривать список сохранённых записей.

## 2. Технологии

- PHP 8.5
- Laravel 13
- MySQL
- HTML
- CSS
- Blade
- Git

## 3. Требования для запуска

Для работы приложения необходимы:

- PHP 8.5 или выше с расширениями PDO и PDO MySQL.
- Composer.
- MySQL.
- Node.js и npm (для установки и сборки frontend-зависимостей).

## 4. Установка проекта

Склонируйте репозиторий:

```bash
git clone https://github.com/kkasyka/student-catalog.git
```

Перейдите в папку проекта:

```bash
cd student-catalog
```

Установите PHP-зависимости:

```bash
composer install
```

Создайте файл окружения:

```bash
cp .env.example .env
```

Для Windows PowerShell можно использовать:

```powershell
Copy-Item .env.example .env
```

Создайте ключ приложения:

```bash
php artisan key:generate
```

Установите frontend-зависимости:

```bash
npm install
```

## 5. Настройка базы данных

Создайте базу данных MySQL с названием `laravel`.

Откройте файл `.env` и настройте подключение:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel
DB_USERNAME=root
DB_PASSWORD=
```

При необходимости укажите собственный логин и пароль MySQL.

## 6. Выполнение миграций

Для создания таблиц в базе данных выполните:

```bash
php artisan migrate
```

В результате будет создана таблица `students` с полями:

- id — идентификатор студента;
- full_name — ФИО;
- group_name — учебная группа;
- email — электронная почта;
- created_at — дата создания записи;
- updated_at — дата обновления записи.

Поле email имеет ограничение уникальности.

## 7. Запуск приложения

Запустите локальный сервер Laravel:

```bash
php artisan serve
```

Откройте приложение в браузере:

http://127.0.0.1:8000

## 8. Доступные страницы

| Адрес | Назначение |
|---|---|
| `/` | Перенаправление на каталог студентов |
| `/students` | Просмотр списка студентов |
| `/students/create` | Форма добавления студента |
| `POST /students` | Сохранение нового студента |

## 9. Возможности приложения

- Просмотр списка студентов.
- Добавление новых студентов.
- Проверка заполнения обязательных полей.
- Проверка правильности формата электронной почты.
- Проверка уникальности email.
- Отображение ошибок валидации.
- Сохранение введённых значений при ошибке.
- Вывод сообщения об успешном добавлении студента.
